Scope and limits

The Python reference attained 19/23 called half-session proxies (82.6%), with four wrong calls, three at confidence ≥ 0.9. Its minimum of eight fields was chosen on that test set. The untuned minimum scored 0.708 on 24 calls or 0.680 with every proxy called. The rule consumed 9.5 of 27.4 fields at the same observed forced accuracy 0.800; all available fields are still scored for the QC view. This is not a validated accuracy or time-saving guarantee.

Stored borderline images give a low-confidence PASS in the reference replay, while full-resolution Python input is inconclusive. Previous canvas resizing could change even the chip call. The new resampler remains fail-closed until its actual browser input path is verified; matching tensors alone is not sufficient.
