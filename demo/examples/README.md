# Example fields for the demo

44 fields bundled for the demo, taken from the OOC Image Dataset acquisition sessions listed below
(12/12/20 fields, spread across each session's acquisition order).

Source: OOC Image Dataset, https://doi.org/10.5281/zenodo.10203721 (Zenodo record: CC-BY-4.0;
the MDPI data descriptor lists CC-BY-SA). Cite: Movčana et al., *Data* 2024, 9, 28.

- `good_chip/` — session 230109, 13% of its fields were labelled `bad` by the experts (12 files)
- `bad_chip/` — session 230405, 100% labelled `bad` (12 files)
- `borderline_chip/` — session 230529, 59% labelled `bad` (20 files)

Only these 44 files are redistributed here, with attribution; the full dataset is not.
